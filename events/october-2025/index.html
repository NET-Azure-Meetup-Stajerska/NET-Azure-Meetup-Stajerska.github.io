.NET & Azure Meetup Štajerska - October 2025

Thursday, 16 October 2025, 18:30 – 21:00Tehnološki park Ptuj

The first official meetup of our community, hosted at Tehnološki park Ptuj. An evening of talks on observability, SQL Server 2025 and Azure IoT.

Speakers

Nicola Paro

Cloud Solution Architect - beanTech S.r.L.

Monitor your IoT asset with Azure free services

Tomaž Kaštrun

SQL Server developer and data scientist

SQL Server 2025 - all new features for better database developer experience

Žan Pokeržnik

Full-stack .NET developer with a decade of experience, sharing real-world lessons from the trenches.

Observability in Action: OpenTelemetry for .NET Developers

Agenda

  1. 18:30 – 18:40

    Registration & Welcome

  2. 18:40 – 18:50

    Keynote

  3. 18:50 – 19:30

    Observability in Action: OpenTelemetry for .NET Developers

    Žan Pokeržnik

    In this talk, we’ll explore how OpenTelemetry provides a vendor-neutral way to achieve observability in .NET. We’ll cover the key concepts, explain the differences between pull and push metrics, and look at the various metric types (counters, gauges, histograms). I’ll also share practical lessons from a real-world project, where enriching metrics with contextual attributes like pod names made the difference between raw numbers and actionable insights.

  4. 19:35 – 20:15

    SQL Server 2025 - all new features for better database developer experience

    Tomaž Kaštrun

    This session will explore the world of SQL Server 2025 and how the landscape is changing with powerful new features designed to boost productivity and flexibility. We will cover: • Vector search with AI models • Native JSON support and indexing • Advanced T-SQL enhancements, including regular expressions and other new T-SQL functionalities • Built-in REST API support for exposing database functionality through REST APIs • Cross-platform development on Windows, Linux, containers, Kubernetes, or Azure SQL VM • Microsoft Fabric mirroring We will also look at how SQL Server 2025 changes the landscape for connectivity and application development — including updates to SQL Server Management Studio (SSMS) and Copilot integration.

  5. 20:20 – 21:00

    Monitor your IoT asset with Azure free services

    Nicola Paro

    My IoT device works, but not really that well: sometimes it jams, and other times is stops working completely. If I had a monitoring system, it would certainly be much better! Fortunately, Azure provides us with many free services: will we be able to use them to build our monitoring infrastructure?
