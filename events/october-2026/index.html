  2. 18:45 – 19:35

    Write Less Code by Writing More Code: C# Source Generators and Roslyn

    Amadej Glasenčnik

    C# Source Generators and the Roslyn compiler sound intimidating, but they are actually a secret weapon for eliminating boilerplate code. In this talk, we’ll break down what source generators are, how they work under the hood, and how you can use them to write code that writes code for you at compile time. We’ll start with a practical, step-by-step example by looking at a basic JSON serializer, and see how popular production libraries like Mapperly work under the hood. From there, we’ll dive into a real-world project I built called TypedIcons, a library that uses source generators to bring type-safe icons and IntelliSense to Blazor. You’ll leave with a clear understanding of how to make the compiler do the heavy lifting for your own projects.

  3. 19:35 – 20:25

    Azure AI Foundry - your go-to AI tool

    Tomaž Kaštrun

    Azure AI Foundry brings multiple services that enable developers to build amazing AI-powered solutions in a single unified experience for AI development on the Azure cloud platform. For a single project you can now use Foundry for multiple tasks in the same environment and enables you better collaboration and faster development. These services are - just to name a few - deploying models from the catalog for real-time inference, deploying and testing generative AI models in Azure OpenAI service, using prompt flow to define workflows that integrate models, prompts, and custom processing, and many safety features, to fine-tuning and several different SDK for language of your choice. Session will give you a walk-through of Azure Foundry with AI Services and dive into AI scenarios that could be enhanced by using AI tools.
